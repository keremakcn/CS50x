# CS50x – Introduction to Computer Science

This repository contains my completed coursework, problem sets, and final project for Harvard University's **CS50x: Introduction to Computer Science**.

---

## Course Overview

CS50x is an entry-level computer science course that covers foundational programming concepts, computational thinking, and software engineering principles. The curriculum begins with low-level programming in C—focusing on memory management, pointers, and data structures—and transitions into higher-level languages and tools including Python, SQL, JavaScript, and web frameworks.

---

## Coursework & Problem Sets

### Week 0: Scratch

* **Concepts:** Computational thinking, event-driven programming, loops, conditions, and variables.
* **Project:** *Scratch Project* – An interactive game designed to practice core control flow and logic without syntax overhead.

### Week 1: C

* **Concepts:** Compiling, syntax, data types, loops, conditionals, and standard I/O.
* **Assignments:**
* `mario` – Recreating the classic Mario pyramid using nested loops.
* `cash` / `credit` – Implementing greedy algorithms to calculate minimum coin change and validating credit card numbers via Luhn's algorithm.



### Week 2: Arrays

* **Concepts:** Arrays, strings as character arrays, command-line arguments, memory layouts, and cryptography basics.
* **Assignments:**
* `readability` – Calculating the reading grade level of text using the Coleman-Liau index.
* `caesar` / `substitution` – Implementing classical ciphers to encrypt text using command-line keys.



### Week 3: Algorithms

* **Concepts:** Algorithmic complexity (Big $O$, $\Omega$, $\Theta$), searching (linear vs. binary), and sorting algorithms (bubble, selection, merge).
* **Assignments:**
* `sort` – Analyzing and identifying mystery sorting algorithms based on run-time characteristics.
* `plurality` – Simulating a simple plurality vote counting system.
* `runoff` – Implementing a ranked-choice instant-runoff voting system.



### Week 4: Memory

* **Concepts:** Pointers, memory allocation (`malloc`, `free`), pointer arithmetic, heap vs. stack, file I/O, and hexadecimal representation.
* **Assignments:**
* `volume` – Modifying audio file volume by reading and writing WAV file headers and samples.
* `filter` – Applying image processing filters (grayscale, reflection, blur, edge detection) to 24-bit uncompressed BMP files.
* `recover` – Recovering deleted JPEG images from a raw memory card dump by identifying file signatures.



### Week 5: Data Structures

* **Concepts:** Abstract data types, linked lists, hash tables, tries, binary search trees, and dynamic memory management.
* **Assignments:**
* `inheritance` – Simulating the inheritance of blood types across generations using recursively allocated structures.
* `speller` – Building a high-performance spell-checker using a hash table data structure and optimizing for lookup speed and clean memory deallocation.



### Week 6: Python

* **Concepts:** Transitioning from C to Python, higher-level data types, Python standard libraries, and working with external data.
* **Assignments:**
* `sentimental` – Re-implementing previous C problem sets (`mario`, `readability`, `cash`/`credit`) in Python to compare language paradigms.
* `dna` – Identifying individuals from a database using Short Tandem Repeat (STR) DNA profiling.



### Week 7: SQL

* **Concepts:** Relational databases, SQL queries (`SELECT`, `INSERT`, `UPDATE`, `JOIN`, `GROUP BY`), indexing, and database normalization.
* **Assignments:**
* `songs` – Writing queries to analyze musical attributes using an SQLite database.
* `movies` – Constructing multi-table relational queries on the IMDb database.
* `fiftyville` – Solving a mystery scenario by cross-referencing crime reports, security logs, ATM transactions, flight manifests, and phone calls using SQL queries.



### Week 8: HTML, CSS, JavaScript

* **Concepts:** Web page structure (HTML5), styling and layout (CSS3, responsive design), DOM manipulation, and event handling (JavaScript).
* **Assignments:**
* `trivia` – An interactive web page featuring multiple-choice and free-response trivia questions with dynamic DOM feedback.
* `homepage` – A personal multi-page website built with semantic HTML, custom CSS styling, and client-side JavaScript.



### Week 9: Flask

* **Concepts:** Web application architecture (MVC/MTV pattern), HTTP methods (`GET`, `POST`), server-side routing, cookies, user sessions, and integrating SQLite with a backend.
* **Assignments:**
* `birthdays` – A web application allowing users to track and persist upcoming birthdays to an SQLite database.
* `finance` – A stock portfolio web app using the IEX Cloud API to fetch real-time stock quotes, buy/sell shares, track user balances, and log transaction histories.

## Final Project: Movie Watchlist

A full-stack web application designed for tracking movies to watch and keeping a personal log of watched films.

* **Stack:** Python, Flask, SQLite, HTML5, CSS3, JavaScript.
* **Features:**
* **User Authentication:** Secure user registration, login, and session management with password hashing.
* **Watchlist Management:** Add titles to a "To Watch" queue or move them to a "Watched" history list.
* **Ratings & Notes:** Record personal ratings and brief notes for viewed titles.
* **Database Persistence:** Stores user records and watchlists via an SQLite database.
* **Responsive UI:** Clean, mobile-friendly interface styled with CSS.

## What I Learned

Working through CS50x provided a ground-up understanding of software development:

1. **Low-Level Mechanics:** Learning C first built an appreciation for how computers manage memory, how data types exist at the byte level, and the computational cost of operations.
2. **Algorithm Design:** Implementing data structures from scratch (like hash tables and linked lists) demystified how higher-level language features work under the hood.
3. **Full-Stack Development:** Transitioning to Python, SQL, and Flask showed how backend services connect to relational databases and serve dynamic web interfaces to users.
