# 🎓 CS50x – Introduction to Computer Science

I completed Harvard University's **CS50x – Introduction to Computer Science** and received the CS50 certificate.

This repository documents my completed CS50x coursework, including problem sets and my final project.

## 📚 Course Overview

CS50x is an introduction to computer science and programming that covers problem solving, algorithms, data structures, memory, databases, web development, and software development using several programming languages and technologies.

Throughout the course, I worked from lower-level programming in C toward Python, SQL, and web development with Flask.

## 📝 Problem Sets

### Week 1 — C

- **Mario** — Practiced loops, conditionals, and formatted output by generating Mario-style pyramids.
- **Cash** — Worked with loops, arithmetic, and program logic for calculating change.
- **Credit** — Practiced conditionals, loops, and working with digits and numbers.

### Week 2 — Arrays

- **Scrabble** — Practiced arrays, strings, character processing, and calculating scores.
- **Readability** — Worked with strings, character counting, and calculating a readability index.
- **Caesar** — Practiced string manipulation and implementing a substitution-based cipher.

### Week 3 — Algorithms

- **Plurality** — Implemented an election system using arrays, functions, and search logic.
- **Runoff** — Worked with ranked-choice voting, arrays, strings, and election algorithms.

### Week 4 — Memory

- **Filter** — Practiced manipulating image data and working with pixels, structures, and memory.
- **Recover** — Worked with files, raw data, and recovering JPEG images from a memory card.

### Week 5 — Data Structures

- **Speller** — Implemented a spell checker using a hash table, dynamic memory allocation, linked structures, and file processing.

### Week 6 — Python

- **Python problem sets** — Revisited programming concepts in Python, including functions, loops, conditionals, strings, and data processing.

### Week 7 — SQL

- **Movies** — Practiced SQL queries, filtering, sorting, aggregation, and joining related tables using SQLite.

### Week 8 — HTML, CSS, JavaScript

- **Homepage** — Built a multi-page website using HTML, CSS, and JavaScript.
- **Trivia** — Built an interactive trivia webpage using HTML, CSS, and JavaScript.

### Week 9 — Flask

- **Finance** — Built a web application with Flask and SQLite, working with routes, templates, forms, sessions, and database operations.
- **Birthdays** — Built a Flask application that stores and displays birthday information using SQLite.

## 🎬 Final Project

### Movie Watchlist

My final project is a personal **movie watchlist web application** built with Flask and SQLite.

The project applies concepts from the course to a larger application, combining a web interface with backend logic and database storage for managing movies and a personal watchlist.

## 🚀 What I Learned

CS50x gave me a progression from basic programming concepts to building complete web applications.

I started with programming fundamentals in C, then worked with algorithms, memory, and data structures before moving to Python and SQL. The later problem sets introduced web development with HTML, CSS, JavaScript, Flask, and SQLite.

The course also helped me become more comfortable reading unfamiliar code, debugging programs, working with data, and breaking larger problems into smaller parts.
